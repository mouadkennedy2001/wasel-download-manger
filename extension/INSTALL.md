# تثبيت إضافة واصل للمتصفح

تعمل الإضافة مع Chrome وEdge وBrave وOpera وFirefox 128 أو أحدث.

## أين أجد مجلد الإضافة؟

افتح واصل ← **الإعدادات ← المتصفح**. ستجد مسار المجلد مع زر «نسخ» وزر «فتح». ينسخ واصل الإضافة إلى هذا المجلد عند كل تشغيل، فتصلك تحديثاتها مع تحديثات التطبيق.

## Chrome وEdge وBrave وOpera

1. افتح `chrome://extensions` (أو `edge://extensions`).
2. فعّل **وضع المطوّر / Developer mode**.
3. اضغط **تحميل إضافة غير محزّمة / Load unpacked** واختر المجلد `chromium` الذي نسخته من واصل.

## Firefox

1. افتح `about:debugging#/runtime/this-firefox`.
2. اضغط **Load Temporary Add-on** واختر ملف `manifest.json` داخل المجلد `firefox`.
3. الإضافة المؤقتة تُزال عند إغلاق Firefox؛ التثبيت الدائم يحتاج توقيعًا من Mozilla.

## ماذا تفعل الإضافة؟

- تلتقط تنزيلات HTTP/HTTPS (اختياريًا، من نافذة الإضافة) وترسلها إلى واصل مع ملفات تعريف الارتباط وصفحة الإحالة، فتعمل التنزيلات التي تتطلب تسجيل الدخول.
- تضيف «Download with Wasel» إلى قائمة النقر بالزر الأيمن على الروابط والفيديو والصوت والصور.
- إن لم يكن واصل يعمل، تترك التنزيل للمتصفح ولا تُضيعه.

## الصلاحيات

`downloads` لالتقاط التنزيلات، و`cookies` مع صلاحية المواقع لإرسال جلسة تسجيل الدخول، و`contextMenus` للقائمة، و`storage` لحفظ إعداد الالتقاط. لا تُرسل أي بيانات إلى خارج جهازك: الاتصال الوحيد هو مع واصل عبر `127.0.0.1`.
